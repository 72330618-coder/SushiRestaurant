# Sushi House - Restaurant Ordering System

## Project Description

Sushi House is a responsive restaurant ordering web application developed using ReactJS. The application allows users to browse sushi items, view prices and descriptions, add products to a shopping cart, remove items, contact the restaurant, and track orders.

## Features

- Responsive design for desktop and mobile devices.
- Home page with restaurant introduction.
- About page with restaurant information.
- Sushi menu with product images, descriptions, and prices.
- Add to Cart functionality.
- Remove items from the shopping cart.
- Clear Cart functionality.
- Contact page with a contact form.
- Track Order page.
- Red, white, black, and gray color theme.
